# Spotify for 3ds
[spotify-streamer](https://github.com/aeryli/spotify-streamer/) client code

## Building*
```
git clone https://github.com/aeryli/spotify.git
cd spotify
make clean
make
```
###### *in msys2
## Cleaning from Build
1. start in build dir
2. run the following code:
   ```
   mv ./spotify/3ds_spotify.3dsx ./3ds_spotify.3dsx
   rm -rf ./spotify/
   ```
